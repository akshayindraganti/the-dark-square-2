# The Dark Square — User Interface Design Description Document

**Direction: The Storybook Grid** — an immersive, editorial layout built around split-screen product pages and a persistent sticky buy-box, designed to carry the brand's "Every Square Holds a Story" promise into every page.

---

## Layout Structure

- **Homepage**: Full-bleed hero → "Chocolate, Crafted With Intention" intro block → "Discover Your Square" collection grid (Classics / Nut Collection / Dark Collection / Celebration) → Lily & Leo teaser strip → gifting banner → Dark Journal preview → footer.
- **Product Page (core Storybook Grid pattern)**: Two-column split. Left column is a sticky media panel (product photography, ingredient close-ups). Right column scrolls independently through name, tasting notes, description, and size selection, ending in a **sticky buy-box** that stays pinned as the page scrolls.
- **Story pages** (Our Story, Why The Dark Square, Ingredient Philosophy, Lily & Leo): Alternating asymmetric two-column blocks — image on one side, copy on the other, flipping sides section to section to create a "turning the page" rhythm.
- **Gifting / Corporate Gifting / Custom Orders**: Split layout pairing an inspirational image column with a form or CTA-forward column (quote request, custom order builder).
- **The Dark Journal**: Card-grid listing page, each card a story teaser (image, title, short excerpt).
- **Contact**: Simple split — contact routes (Customer Support / Corporate Gifting / Collaborations) on one side, form on the other.
- **Footer**: Four-column link structure (Shop / Discover / Gifting / Help) beneath the tagline "Every Square Holds a Story."

## Core Components

- **Sticky Buy-Box**: product name, chocolate type/%, size selector (50g / 100g), price, "Add to My Squares" CTA.
- **Collection Card**: used in "Discover Your Square" and Shop grid; image, collection name, one-line description.
- **Product Card**: thumbnail, name, short descriptor, price.
- **Navigation Bar**: mega-menu structured around the footer taxonomy (Shop / Discover / Gifting / Help).
- **Cart Drawer**: labeled "Your Squares"; empty state reads "Your chocolate story hasn't begun yet."
- **Lily & Leo Module**: recurring character callout block, used on homepage, product pages (back-of-pack story), and Journal.
- **Tasting Notes Strip**: Cocoa / Texture / Finish, shown as a compact horizontal strip on product pages.
- **Story Quote Block**: pull-quote style module for Our Story and Journal content.
- **Corporate Quote Form**: multi-field enquiry form for bulk/corporate gifting.
- **Custom Order Builder**: step-based form (flavour, packaging, message, occasion).
- **Journal Card**: image + title + excerpt, used in grid and homepage preview.
- **Newsletter Signup**: footer-embedded.

## Interaction Patterns

- **Scroll-sync split screen**: on product pages, the media panel stays pinned while the copy column scrolls past it; the buy-box remains visible at all times.
- **Hover reveal (desktop)**: collection cards reveal a secondary tasting-note or ingredient detail on hover.
- **Tap-to-expand (mobile)**: the same detail is revealed via tap, since hover isn't available.
- **Add-to-cart confirmation**: adding a product slides in the "Your Squares" cart drawer from the right with a brief confirmation state.
- **Anchor-scroll navigation**: homepage sections (Discover Your Square, Gifting, Journal) are reachable via smooth anchor scroll from the nav or hero CTAs.
- **Progressive disclosure**: the Custom Order builder reveals one decision at a time (flavour → packaging → message → review) rather than a single long form.
- **Restrained motion for Lily & Leo elements**: small, playful micro-animations (e.g., a gentle bounce or blink) — enough to feel alive, never cartoonish or distracting from the premium tone.

## Visual Design Elements & Color Scheme

- **Palette**: Deep Cocoa `#21140F`, Espresso `#180D09`, Copper `#D49B84`, Warm Cream `#F3E8DD`, Cocoa Taupe `#80594A`.
- Copper is used as an **accent only** (CTAs, dividers, highlights) — never as a flood color.
- Dark surfaces use Espresso/Deep Cocoa rather than pure black, keeping the palette warm rather than cold.
- Generous whitespace and "breathing room" throughout — the brand playbook explicitly warns against cluttered, noisy layouts.
- Thin rule dividers or simple line breaks between content sections, echoing the understated, editorial feel of the brand copy document.
- Photography-led visual language; minimal decorative elements unless they serve the story (per playbook: "if an element does not improve the story... remove it").

## Mobile, Web App, Desktop Considerations

- **Desktop**: Full split-screen product layout with sticky side-by-side panels; hover states enabled; wide mega-menu navigation.
- **Mobile**: Single-column stacking — media panel first, then scrollable content; the sticky buy-box collapses into a slim bar fixed to the bottom of the viewport (size + Add to My Squares) rather than a side panel.
- **Collection grids**: swipeable horizontal carousels on mobile instead of a fixed grid.
- **Forms** (Custom Order, Corporate Quote): step-by-step on mobile to avoid long scroll; can show more fields per screen on desktop.
- This is scoped as a **responsive website**, not a native app — no separate app-specific patterns required unless a future native app is scoped.

## Typography

- **Primary (headlines, product names, brand moments)**: Playfair Display — a high-contrast serif that carries the "premium/elegant" pillar.
- **Secondary (body copy, UI labels, forms, navigation)**: Lato — a clean sans-serif for legibility and information density.
- **Accent (Lily & Leo story moments only)**: a restrained handwritten-style typeface, used sparingly and never for primary UI or commerce content.
- Maintain a clear type hierarchy: large serif headlines, generously spaced sans-serif body text (16px+ base), and comfortable line-height to reinforce the unhurried, premium feel described in the Voice & Tone guidelines.

## Accessibility

- Verify color contrast for text-on-background combinations, particularly Copper `#D49B84` against Warm Cream and Espresso — confirm WCAG AA (4.5:1) before finalizing CTA and link colors.
- Any information revealed via hover (desktop collection card details) must have an equivalent tap/focus-triggered state — never hide essential content behind hover alone.
- All product photography and Lily & Leo illustrations require descriptive alt text, since the character illustrations carry narrative meaning, not just decoration.
- Form fields (Custom Order, Corporate Quote, Contact) need clear labels, visible focus states, and accessible error messaging.
- Sticky mobile buy-bar and all tap targets should meet a minimum 44×44px touch size.
- Ensure the scroll-sync split-screen pattern degrades gracefully for screen readers and keyboard navigation — content should still read in a logical linear order when CSS positioning is stripped away.
