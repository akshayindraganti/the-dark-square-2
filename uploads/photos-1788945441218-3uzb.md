# System Design — The Dark Square (Artisan Chocolates Ecommerce Website)

_Every Square Holds a Story._

Reference context: Brand Playbook & Guidelines v1.0, Website Content & Brand Copy. Shipping: India only. Payments: UPI / Cards / Netbanking via Razorpay.

## Architecture Pattern

- **Full-stack monolith on Next.js (App Router)** — frontend, backend API, and admin panel live in one codebase and one deployment.
- Layered structure: **Presentation** (Server/Client Components) → **API Layer** (Route Handlers / Server Actions) → **Service Layer** (business logic: pricing, order creation, inquiry routing) → **Data Access Layer** (Prisma) → **PostgreSQL**.
- **Admin panel** is a protected route group (`/admin/**`) inside the same app — no separate service — for managing products, collections, orders, Journal posts, and gifting/custom-order inquiries.
- **Media** (product photography, Lily & Leo illustrations, Journal images) lives in **AWS S3**, served through Next/Image with a custom S3 loader or CloudFront.
- Rendering strategy: Static/ISR for content-heavy pages (Home, Our Story, Collections, Product, Journal), dynamic/server-rendered for account, cart, and checkout.

## State Management

- **Cart ("Your Squares")**: client-side state via Zustand, persisted to `localStorage` for guests; synced to the server (`CartItem` table) on login/checkout so it survives across devices.
- **Server data**: fetched via React Server Components where possible; client-side reads/mutations (cart count, wishlist, order status polling) use React Query for caching and optimistic updates.
- **Auth/session state**: NextAuth.js JWT session, read via `useSession()` client-side or `auth()` server-side.
- **Forms**: React Hook Form + Zod validation for Checkout, Custom Order, Corporate Gifting, and Contact forms.
- **Admin UI state**: local component state + React Query for CRUD lists (products, orders, journal posts).

## Data Flow

**Shopping flow:**
Browse Collection → Product Detail → Add to Cart (optimistic client update, background sync if logged in) → Cart review → Checkout (address form; India-only validation) → Create Razorpay order (server) → Razorpay checkout widget → Payment success/failure → Razorpay webhook confirms payment signature → Order + OrderItems persisted, Cart cleared → Confirmation email → Order visible in `/account/orders`.

**Inquiry flow (Corporate Gifting / Custom Orders / Contact):**
Form submit → Server Action validates + writes to `CorporateGiftingInquiry` / `CustomOrderRequest` / `ContactMessage` → Notification email to internal team → Status tracked in Admin panel (New → In Progress → Closed). No payment at submission stage — these are quote-driven.

**Content flow:**
Admin creates/edits Product, Collection, or Journal entry in `/admin` → written to DB, images uploaded to S3 → relevant public pages revalidated (ISR/on-demand revalidation) → visible on storefront.

**Newsletter flow:**
Footer/inline form → email stored in `NewsletterSubscriber` → confirmation email → available for export/integration with an email tool later.

## Authentication Process

- **Providers (NextAuth.js), all three enabled:**
  - **Email + Password** — bcrypt-hashed, stored in `User` table.
  - **Email OTP** — passwordless; a short-lived code/token is emailed and verified server-side.
  - **Google OAuth** — social login, auto-creates/links `User` by email.
- **Guest checkout** is supported: an order can be placed without an account, linked to the order's email; the customer can optionally create an account post-purchase to claim order history.
- **Session**: JWT strategy in an httpOnly cookie.
- **Roles**: `customer` (default), `admin`. `/admin/**` routes are gated by middleware checking `role === "admin"`.
- **Account area**: profile, saved addresses, order history, saved items ("Your Squares" wishlist).

## API Design

| Method              | Endpoint                     | Purpose                                           | Auth                                  |
| ------------------- | ---------------------------- | ------------------------------------------------- | ------------------------------------- |
| GET                 | `/api/products`              | List/filter products by collection                | Public                                |
| GET                 | `/api/products/[slug]`       | Product detail                                    | Public                                |
| GET/POST/PUT/DELETE | `/api/admin/products`        | Product CRUD                                      | Admin                                 |
| GET                 | `/api/collections`           | List collections                                  | Public                                |
| GET/PUT             | `/api/cart`                  | Get/update current cart                           | Public (guest cookie) or Customer     |
| POST                | `/api/checkout/create-order` | Create Razorpay order for cart total              | Public/Customer                       |
| POST                | `/api/checkout/webhook`      | Verify Razorpay payment signature, finalize order | Razorpay (signed)                     |
| GET                 | `/api/orders/[id]`           | Order status/detail                               | Customer (owner) or guest email match |
| GET                 | `/api/admin/orders`          | List/manage all orders                            | Admin                                 |
| POST                | `/api/auth/[...nextauth]`    | Login, OTP, OAuth callbacks                       | Public                                |
| POST                | `/api/corporate-gifting`     | Submit corporate gifting inquiry                  | Public                                |
| POST                | `/api/custom-orders`         | Submit custom order request                       | Public                                |
| POST                | `/api/contact`               | Submit contact message                            | Public                                |
| GET/POST            | `/api/journal`               | List / create Journal posts                       | Public (GET) / Admin (POST)           |
| POST                | `/api/newsletter`            | Subscribe email                                   | Public                                |
| GET/PUT             | `/api/account/addresses`     | Manage saved addresses                            | Customer                              |

## Database Design (ERD)

**User** (id, name, email, passwordHash?, role, createdAt)
&nbsp;&nbsp;→ has many **Address**
&nbsp;&nbsp;→ has many **Order**
&nbsp;&nbsp;→ has one **Cart**
&nbsp;&nbsp;→ has many **WishlistItem**

**Address** (id, userId, line1, line2, city, state, pincode, phone, isDefault)

**Collection** (id, name, slug, description) — Classics / Nut Collection / Dark Collection / Celebration Collection
&nbsp;&nbsp;→ has many **Product**

**Product** (id, collectionId, name, slug, description, tastingNotes, chocolateType, images[] → S3 keys, isActive)
&nbsp;&nbsp;→ has many **ProductVariant**

**ProductVariant** (id, productId, size — e.g. 50g/100g, price, stockQty, sku)

**Cart** (id, userId?, guestToken?)
&nbsp;&nbsp;→ has many **CartItem**

**CartItem** (id, cartId, productVariantId, quantity)

**Order** (id, userId?, guestEmail?, addressId, subtotal, shippingFee, total, status — Pending/Paid/Shipped/Delivered/Cancelled, createdAt)
&nbsp;&nbsp;→ has many **OrderItem**
&nbsp;&nbsp;→ has one **Payment**

**OrderItem** (id, orderId, productVariantId, quantity, priceAtPurchase)

**Payment** (id, orderId, razorpayOrderId, razorpayPaymentId, razorpaySignature, status, amount)

**WishlistItem** (id, userId, productId)

**JournalPost** (id, title, slug, coverImage, body, publishedAt)

**CorporateGiftingInquiry** (id, companyName, contactName, email, phone, requirement, status)

**CustomOrderRequest** (id, name, email, phone, occasion, details, status)

**ContactMessage** (id, name, email, category — Support/Corporate/Collaboration, message, status)

**NewsletterSubscriber** (id, email, subscribedAt)
